# generic-small-animal-fighting-game-2023
Welcome, player! to the wonderful world of Pokémon—ahem, I mean, generic small animals. Your first opponent will be this...thing here. Attack with arrow keys to do random amounts of damage/healing, but be warned the enemy is just as strong as you and will attack! 

Each attack does a certain range of damage/healing, but your strongest attack and healing potion have cooldown periods, so be careful using them.

This project is made for Greenfoot 3.8+. It might work on older versions, but that is not guaranteed.
